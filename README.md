# Lazy Chunk Entity Rendering Fix

A Fabric mod for Minecraft that fixes rendering for entities inside lazy chunks by freezing the entities. even when using`/gamerule spectatorGenerateChunks false` and `/carpet creativePlayerLoadChunks false`
credit
* **XSY_xiaoqi** - Original author of Carpet-VisualFix
* **abctools123** - ported to 1.21.11 and fixed for spectators

* **Minecraft:** `1.21.11`
* **Loader:** Fabric Loader (latest recommended)
* **Required Dependency:** [Carpet](https://modrinth.com/mod/carpet)
* **Side:** [Server and Client]

to use mod run
/carpet lazyEntityRenderingFix true
